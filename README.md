# 24BSE1211-PDE-MicroProject-Group-4-

1D Image Blurring and Restoration

A mathematical and computational study of 1D image blurring and restoration using the Heat Equation.

📌 Project Phases

Phase 1 — Theoretical

Derivation of the 1D heat equation solution using separation of variables and Fourier sine series, including frequency-dependent decay and the challenges of image restoration.

Phase 2 — Computational

Python implementation and visualization of the analytical solution, including:

- Fourier reconstruction of a step edge
- Image blurring over time
- Frequency-dependent decay
- Decay-time verification
- PDE numerical verification
- Inverse diffusion and noise amplification
- Regularized image restoration

🛠️ Technologies

- Python
- NumPy
- Matplotlib
- Fourier Series
- Heat/Diffusion Equation
